# Tessera Sign Studio

Type a word, pick a style, and get a tile-by-tile mosaic sign you can use as a real template for ceramic tiles or fuse beads.

Plain HTML, CSS and JavaScript. No build step, no backend: everything runs in the browser.

## Run locally

    git clone https://github.com/mikenev/tessera-sign-studio
    cd tessera-sign-studio
    python3 -m http.server 8000

Then open http://localhost:8000.

## Fonts

The bitmap fonts in `js/fonts.js` are original drawings, released under CC0 (see `fonts/LICENSE-fonts.txt`).
All style presets are original designs. The project uses no transit agency names, logos, route bullets or trademarked lettering.
